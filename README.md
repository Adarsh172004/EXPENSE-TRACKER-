# Smart Expense Tracker and Financial Dashboard

A modern and responsive expense management web application built using React.js. The application helps users manage income and expenses, visualize spending patterns, set budgets, track goals, and generate reports.

## Features

### Transaction Management
- Add transactions
- Edit transactions
- Delete transactions
- Category selection
- Date picker

### Dashboard
- Current Balance Card
- Income Card
- Expense Card
- Savings Card

### Analytics
- Pie Chart for category-wise spending
- Bar Chart for monthly expenses
- Income vs Expense line chart

### Budget Management
- Monthly budget limit
- Budget alerts
- Progress bars

### Goal Tracker
- Multiple savings goals
- Goal progress tracking

### Search and Filter
- Search transactions
- Filter by category
- Filter by transaction type
- Sort by amount and date

### Export Features
- Export transactions to CSV
- Download PDF reports

### User Experience
- Dark Mode
- Toast notifications
- Loading spinner
- Responsive design
- Smooth animations

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/smart-expense-tracker.git
```

Navigate to the project folder:

```bash
cd smart-expense-tracker
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
